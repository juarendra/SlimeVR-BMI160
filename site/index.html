Step 06 · Documentation

Hardware overview & reference

Informasi lengkap komponen internal tracker dan layout PCB SlimeVR-BMI160.

Produk Jadi — Komponen Internal

Setiap unit tracker terdiri dari komponen berikut:

  • Casing 3D-Print — Enclosure kompak (FDM/resin), desain snap-fit dengan lubang USB-C dan slide switch
  • PCB Utama — Board custom berukuran kompak yang memuat seluruh sirkuit elektronik
  • ESP32-WROOM-32D — Mikrokontroler WiFi 802.11 b/g/n + BLE 4.2, dual-core 240 MHz
  • BMI160 (IMU) — Sensor 6-axis (accelerometer + gyroscope), terpasang via header 7-pin (mudah diganti)
  • Baterai Li-Ion / LiPo — Sumber daya wireless, konektor JST-PH 2-pin
  • Port USB Type-C — Pengisian baterai dan flashing firmware
  • Slide Switch (On/Off) — Saklar daya di sisi casing
  • 5 LED Indikator — Charging (biru), Standby/penuh (merah), ACK (merah, berkedip saat server aktif), TX/RX (serial)
  • Elastic Strap — Tali elastis untuk pemasangan di tubuh

Full-body tracking membutuhkan 5–7 unit tracker (minimal: paha kiri-kanan, betis kiri-kanan, dada/hip).

Layout PCB & Pinout

Bagian-bagian utama PCB:

  • ESP32-WROOM-32D — Modul utama di tengah PCB, antena WiFi di ujung (jangan tutup dengan ground plane)
  • FT231XS-R — IC USB-to-UART di dekat konektor USB-C, untuk flashing dan serial monitor
  • TP4056 — IC charger baterai Li-Ion (constant current/voltage)
  • DW01A + FS8205A — Proteksi baterai: over-charge, over-discharge, overcurrent, short circuit
  • M3406-ADJ — DC-DC step-down 3.7–4.2V → 3.3V untuk ESP32 dan sensor
  • USB Type-C — Port input: pengisian daya + komunikasi serial
  • Header IMU 7-pin — Socket modular untuk BMI160 (bisa dilepas/ganti tanpa solder)
  • JST-PH 2-pin (P1) — Konektor baterai Li-Ion/LiPo
  • JST-PH 4-pin (EXT) — Port I2C ekspansi untuk sensor tambahan
  • Slide Switch — Saklar on/off yang memutus jalur daya baterai
  • Tombol Reset — Reset manual ESP32
  • 5 LED SMD — CHRG, STBY, LED (ACK), TX, RX
  • Q1, Q2 (MMBT3904) — Auto-reset ESP32 saat flashing via USB
  • D1 (1N5819HW) — Dioda Schottky proteksi reverse polarity USB

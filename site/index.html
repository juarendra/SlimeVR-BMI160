Step 02 · Flash firmware

Erase & write the tracker image

Web Serial + ESP Web Tools will write the signed firmware directly to the ESP32. Your custom resistor divider (R1=1kΩ, R2=1.82kΩ) and IMU orientation are baked into the image.

ESP32-WROOM-32 BMI160 IMU MPU-6050 drop-in R1=1k · R2=1.82k

Step 03 · WiFi setup

Send credentials to the tracker

Credentials travel only over the local USB serial link — never via the browser or any server. Use 8–63 chars for WPA/WPA2 networks.

Step 05 · Serial log

Tips

  • Close the port in other tabs first
  • Re-plug the tracker if no output
  • Use clear to reset the buffer

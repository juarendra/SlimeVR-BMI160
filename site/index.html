Inspect Device

Ensure your SlimeVR BMI160 tracker is connected to this computer via USB. Click Connect Serial above to link your tracker port. Use the step rail on the left to navigate.

Troubleshooting
  • Install CH340/CP2102 USB driver if device not detected
  • Try different USB cable (must support data transfer)
  • Check Device Manager for COM port assignment
  • Close PlatformIO/Serial Monitor if open

Flash Firmware

This will flash the generic SlimeVR BMI160 firmware to your tracker. Your custom resistor divider (R1=1k, R2=1.82k) and IMU orientation will be preserved.

Note: After flashing, the device will reboot. Wait for the serial port to reappear before proceeding to WiFi setup.

WiFi Setup

Enter your WiFi credentials. They will be sent directly to your tracker over USB serial. Credentials are never sent to GitHub or any server.

Required: 8-63 characters for WPA/WPA2 networks

Serial Log

Live stream from your tracker's USB serial port. Useful for debugging boot, WiFi, IMU, or SlimeVR protocol output. The stream is read-only; no commands are sent here (use the WiFi Setup step for provisioning). 

// Serial log will appear here once streaming starts.

Tips

  • 115200 baud is used to match the firmware default.
  • If the port is already open in another tab, close it first.
  • Re-plug the tracker if you see no output after pressing Start.
Privacy: All WiFi credentials remain in browser memory and travel only over local USB serial.
